- Opening “portfolio project” and simplified simulator framing no longer expresses the target workbench.
- “Pit Wall Intelligence,” “Race Engineer,” “AI,” and “elite” language implies authority beyond validated capability.
- Live deployment and Milestone 1/2 release-candidate narrative describes release history, not the new product boundary.

- Product-tour screenshots preserve the marketing shell and must be replaced after V2.5, not now.
